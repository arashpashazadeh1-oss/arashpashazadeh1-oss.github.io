V11.8 — Conference page square cards

Changes in this version:
- Conference events are no longer shown as long horizontal rectangles.
- The conferences page now uses square-style cards.
- Card order is now visually:
  1) image on top
  2) event name
  3) year
  4) location
- The old header row (Image / Event / Year / Location) is hidden.
- Desktop: 3 cards per row
- Tablet: 2 cards per row
- Mobile: 1 card per row
- Cache-busting added to conferences.html so the new style loads immediately.

Files changed:
- conferences.html
- styles.css
